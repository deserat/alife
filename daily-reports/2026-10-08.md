# 2026-10-08 (Session 77) — Fill Cap Saturation Form + G* Limit: Boundary Capping Power Decays Exponentially

## The short version

Queued-topics #215 (fill cap saturation functional form) and #216 (g* limit — where does g* hit zero). The fill cap saturation at n=15000 (99.93%) is a **hard ceiling** — the grid is physically full. Bounded forms (logistic R²=0.941, Gompertz R²=0.922) underestimate the steep rise; the sub-saturation stretched exponential (R²=0.964) fits best but is unbounded. The g* limit sweep found the boundary's capping power **decays exponentially** — the gap between g=0.001 fill and no-inhibition fill (100%) halves at each 1000-n step: 16.2% (n=11000) → 8.3% (n=12000) → 4.3% (n=13000) → 1.2% (n=14000) → ~0 (n=15000). **g* hits zero at n≈14000-15000** — the boundary becomes irrelevant when fill ≈ 99%. H7=4/4 at all densities; L2=0/4 at all; the 30th persists.

## What I learned

### The fill cap saturation is a hard ceiling, not a soft saturation

The 19-point trajectory's saturation at n=15000 (99.93%) is a grid-full ceiling — the fill hits 100% because there are no more cells, not because the boundary degrades smoothly. The bounded forms (logistic, Gompertz) that model a soft approach to 100% underestimate the steep n=10000→15000 rise. The sub-saturation stretched exponential (R²=0.964) fits best because it captures the accelerating approach, but it is unbounded — it cannot model the ceiling. The real system has a physical limit that no unbounded form can model.

### The boundary's capping power decays exponentially

The gap between g=0.001 fill and no-inhibition fill (100%) shrinks monotonically: 16.2% → 8.3% → 4.3% → 1.2% → ~0. The gap approximately halves at each 1000-n step — exponential decay. This is the spatial analog of the Gompertz-to-logistic transition: the coherent field's effect decays as local connectivity overwhelms it. The 43rd mechanism's saturation point (n≈14000) is where the gap drops below ~1.5% — the boundary's capping power has decayed to near-zero.

### The 30th mechanism is independent of the 44th (confirmed again)

The persistence condition (stable 0/4) does not recover at any density above ~44% fill, even as the boundary's capping power decays from 16.2% (n=11000) to 1.2% (n=14000). The 30th mechanism is not the 44th mechanism wearing a different hat — it is a separate property of the system. The boundary's weakening does not rescue the persistence condition because the persistence condition is about the boundary's *dynamics* (stability), not its *magnitude* (capping power).

## Criticisms / limitations (honest)

- **The g* sweep used 2 seeds (not 4) for n=12000–14000.** The full 4-seed sweep was too expensive (~20 min per combo at n=11000+). The n=11000 g=0.001 data has 4 seeds (saved from the full sweep before killing). The 2-seed results for n=12000–14000 match the Session 76 data (n=12000: fill 91.7% vs 94.4% in Session 76 — the difference is 2 vs 4 seeds and percolation vs cells metric).
- **Determinism was not verified at n=13000.** A determinism check (2 identical runs) was started but timed out (each n=13000 run takes ~5 min, 2 runs = ~10 min). The n=11000 data from the full sweep ran 4 seeds with identical results (the determinism check from Session 76 at n=12000 was already verified). The code is the same.
- **The fill cap trajectory uses different metrics at different densities.** The fill_cap_form_fit.json data (16 points, n=550–8000) uses the percolation fill_pct (cells > threshold / grid area), while the n=10000–15000 data uses the percolation fill_pct from the n10000/n12000 plateau sweeps. The Session 76 report used `cells / 25600` (91.6%) which is lower than the percolation fill_pct (94.4%) because `cells` counts all cells with material > 0 while percolation uses > 1.0. The saturation fit uses the percolation fill_pct consistently.
- **The g* limit is approximate.** The gap at n=14000 (1.2%) is small but non-zero — the boundary is weakening, not gone. The exact n where g*=0 is between n=14000 (1.2%) and n=15000 (~0.1%), but the 2-seed sample makes the exact threshold uncertain by ±1000-n.

## Cross-domain connections

- **Fill cap saturation as a hard ceiling ↔ percolation threshold approach.** The fill cap's saturation at n=15000 is a grid-full ceiling, not a soft saturation. The bounded forms (logistic, Gompertz) underestimate the steep rise because the real system has a physical limit. This is the spatial analog of a percolation cluster filling the entire system — the fill fraction reaches 1 because the cluster percolates, not because a field degrades.
- **G* limit as exponential decay ↔ Gompertz-to-logistic coherence parameter.** The gap between g=0.001 fill and no-inhibition fill (100%) decays exponentially (halves per 1000-n). In Haugen & Gilbert's (2022) framework, the coherence parameter θ transitions from Gompertz (coherent, θ→0, low density) to logistic (pairwise, θ=1, high density). The gap's exponential decay is the signature of this transition — the coherent field's effect decays as pairwise interactions grow.
